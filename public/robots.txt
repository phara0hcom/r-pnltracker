# pnl.tamerelsayed.com — a private, single-user financial tracker.
#
# There is nothing here to index. Every route sits behind `_authed`, which
# redirects to sign-in before any loader touches the database, and sign-in is
# restricted to one allowlisted address. A crawler that ignores this file
# reaches a login page, not data.
#
# The wildcard block below is the rule that actually does the work — a
# compliant crawler needs nothing more. The named agents that follow are
# deliberate redundancy and documentation of intent: several AI vendors gate
# training-corpus collection behind their own product token, and naming them
# leaves no ambiguity about consent if their handling of `*` ever changes.

User-agent: *
Disallow: /
